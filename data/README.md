# Data directory

Large source archives, reference genomes, and raw variant-call
datasets are intentionally not bundled here.

Before running an analysis:

1. Obtain source data from the original provider.
2. Verify sample identifiers, genome assembly, and file provenance.
3. Confirm callable genomic intervals are available for the samples
   being analysed.
4. Do not replace missing callable denominators with coverage depth
   or bin totals unless a validated method supports that substitution.
5. Record data versions, access dates, and applicable licences.
